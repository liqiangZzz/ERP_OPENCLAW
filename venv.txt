ERP_OPENCLAW 本地环境（macOS + conda，Python 3.11.15）

建环境
-----
  conda create -n ERP_OPENCLAW python=3.11.15 -y     # 同名环境已存在时 create 会直接报错
  conda activate ERP_OPENCLAW
  pip install -r requirements.txt                    # 完整锁文件：运行时 + dev + 项目自身
  cd frontend && npm ci

装之前先就位（这三样不起来自代码里看不出来，且失败是静默的）
-----------------------------------------------------------
  MongoDB        .env 的 MONGODB_URI，默认 mongodb://localhost:27017；不起则会话列表为空
  沙箱服务       .env 的 SANDBOX_DOMAIN，当前 http://192.168.0.188:8080；内网地址，换网即不通
  Xcode CLT      xcode-select --install；forbiddenfruit / tavily 只有 sdist，需要本地编译

验证与启动
----------
  pip check && make check PYTHON=$(which python)
  python start_web.py                                # 或 make mcp / make backend / make frontend
